# 🔍 Reya Jindal — Google Search Portfolio & Resume

A creative, modern, interactive developer portfolio designed as an authentic **Google Search experience** in dark mode. Built with pure **HTML5, CSS3, and JavaScript** with zero dependencies.

---

## 🌟 How the Google Portfolio Works

1. **Front Page (Google Home)**:
   * Features the iconic Google layout with a multi-colored **REYA** logo (Blue, Red, Yellow, Green).
   * Animated search bar that types out: `"Hi, my name is Reya Jindal"`.
   * **Google Search** and **I'm Feeling Lucky** buttons, plus quick-explore pill tags (*About Me*, *Projects*, *Skills*, *Experience*, *Contact*).

2. **Search Results Page (SERP)**:
   * Pressing Enter or clicking Search opens the realistic Google Search Results view!
   * **Left Column**: Organic search results with real URLs, breadcrumbs, titles, snippets, sitelinks, and tech stack tags.
   * **Right Column**: Google **Knowledge Graph Panel** summarizing Reya Jindal's bio, education, core languages (C++, Python), and social links.
   * **Filter Tabs**: Click *All*, *Projects*, *Skills*, *Experience*, or *Contact* to dynamically filter results.
   * Click the mini **REYA** logo at any time to return back to the front page!
